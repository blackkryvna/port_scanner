# Port Scanner (C++)

Простой сканер портов на C++, который проверяет список популярных портов на заданном IP-адресе и показывает, какие из них открыты.

Учебный проект — написан пошагово для изучения сетевого программирования на C++ (сокеты, TCP/IP) в контексте кибербезопасности.

## Возможности

- Сканирование одного IP-адреса
- Проверка списка популярных портов (FTP, SSH, HTTP, HTTPS, MySQL, RDP и др.)
- Вывод названия сервиса рядом с номером порта
- Подсчёт общего количества открытых портов

## Список проверяемых портов

| Порт | Сервис     |
|------|------------|
| 21   | FTP        |
| 22   | SSH        |
| 23   | Telnet     |
| 25   | SMTP       |
| 53   | DNS        |
| 80   | HTTP       |
| 110  | POP3       |
| 143  | IMAP       |
| 443  | HTTPS      |
| 445  | SMB        |
| 3306 | MySQL      |
| 3389 | RDP        |
| 5432 | PostgreSQL |
| 8080 | HTTP-Alt   |

## Требования

- Linux (используются POSIX-сокеты: `sys/socket.h`, `netinet/in.h`, `arpa/inet.h`, `unistd.h`)
- Компилятор с поддержкой C++11 или новее (g++, clang++)

## Сборка

```bash
g++ -o scanner scanner.cpp
```

## Использование

```bash
./scanner
```

Программа запросит IP-адрес для сканирования:

```
Введите IP адрес для сканирования: 127.0.0.1

Сканирую 127.0.0.1 (популярные порты)...
Порт 22 (SSH) ОТКРЫТ!

Всего открыто портов: 1
```

## Как это работает

Для каждого порта из списка создаётся TCP-сокет и делается попытка `connect()` к паре `ip:port`. Если подключение проходит успешно (`connect()` возвращает `0`) — порт считается открытым.

Такой подход называется **TCP connect scan** — самый простой и надёжный вид сканирования, но и самый заметный (в отличие от, например, SYN-сканирования, которое использует "полуоткрытые" соединения).

## Дисклеймер

Инструмент создан в учебных целях. Сканируй только те хосты, на которые у тебя есть разрешение (свой компьютер, свой роутер, собственные тестовые серверы). Сканирование чужих систем без разрешения может быть незаконным.
